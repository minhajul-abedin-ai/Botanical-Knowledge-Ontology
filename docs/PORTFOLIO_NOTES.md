# Portfolio notes

This project is intended to demonstrate practical knowledge of:

- Knowledge engineering
- Ontology modelling
- Semantic Web standards
- OWL/RDF representation
- SPARQL querying
- Logical constraints and consistency checking
- Knowledge graphs
- Neuro-symbolic AI concepts
- Reproducible Python tooling

## What not to claim

Do not describe this repository as the exact original coursework submission. The original `.owl` / Protégé project was unavailable. This repository was reconstructed from the written assignment and then extended with reproducibility tooling for portfolio use.

## Suggested interview explanation

> I originally developed a botanical knowledge-engineering assignment in Protégé. I no longer had the original ontology file, so I reconstructed the ontology from the report, clearly separated source-supported facts from portfolio additions, and built a reproducible RDFLib pipeline, SPARQL queries, tests and documentation around it.
